Interactive Smart Robot Car and Sensor Monitoring System

An educational browser simulation of five embedded sensors, tested individually and then integrated into one autonomous robot car.

Introduction

Robots perceive their surroundings through sensors. This project demonstrates the working principle of five low-cost sensors common in Arduino-based robot cars, then combines them in a 2D simulated environment.

Problem statement

A mobile robot must avoid obstacles, monitor its environment, accept remote commands, and detect rough or unstable terrain. Testing each sensor alone and then together shows how their data fuse into safe behaviour.

Objectives

  • Understand each sensor's working principle through interaction
  • Compute every reading from simulated physical state
  • Integrate all sensors into one obstacle-avoiding robot

The five sensors

  1. HC-SR04 ultrasonic sensor — distance by echo time
  2. DHT11 — temperature and humidity
  3. IR receiver — decodes remote commands (NEC-style)
  4. Vibration sensor — detects shocks and rough terrain
  5. Tilt sensor — detects abnormal orientation

Working principle

Controls change the simulation state (object position, environment, button presses, events, orientation). Sensor models read that state, and the robot's decision logic reacts to the readings.

System architecture

How the sensors work together

  • Ultrasonic ray-cast from the robot's heading gives distance; the robot brakes (or turns in auto mode).
  • IR commands set motion; DHT11 follows the ambient controls.
  • Rough road and impacts trigger the vibration sensor; the ramp changes pitch for the tilt sensor.
